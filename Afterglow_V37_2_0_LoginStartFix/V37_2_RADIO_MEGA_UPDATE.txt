AFTERGLOW V37.2.0 - RADIO MEGA UPDATE

핵심:
- 벙커에 실제 라디오 가구 추가
- 사용자가 제공한 radio.png 사용
- 60초 수집 단계에서 라디오를 가져온 경우 사용 가능
- 라디오 신호 로그 / 자동 신호 준비 / Tune 시스템
- 전력 0에서는 라디오 사용 불가

Radio Events:
1) Game Show
- 수락/거절
- 8칸 구조 룰렛 (Supplies 결과 2칸)
- 체력 감소 / 카타나 / 보스 / 보급품 / 보급품 손실 /
  최대 체력 증가 / 질병
- 카타나 실제 무기 추가 (공격 62, 빠른 쿨다운)

2) SOS Message
- 해독 시 Sanity Stat -35
- SOS Location 좌표 unlock
- 라디오 로그 기록

3) Radio Interference
- 수락 후 라디오 재밍
- Radio Interference Location 좌표 unlock
- 재밍 중 다른 채널 사용 불가
- 현재 버전 임시 복구: 공구함1+배터리1
- 다음 버전에서 원작형 탐사지 + 안테나 3개로 교체 예정

4) Homeless Dude
- 통조림 2 + 물 2 필요
- 약 60초 뒤 랜덤 결과
  guard: 주기적으로 외부 CCTV 위협 제거
  mold: 벙커 플레이어 위생 지속 감소
  dead: 사망
- 내보내기 가능
- 내보낼 경우 일정 확률로 적대 Raider 생성

Special:
5) Aliens? / Unknown Channel
- 통조림2 + 물2 + 메디킷2 + 지도1
- 특수 신호 루트 시작
- 상태/로그 저장

멀티플레이:
- 라디오 상태 서버 동기화
- 이벤트 결과 자원/무기/개인상태 동기화
- 모든 플레이어에게 신호 ready/event 상태 전송

주의:
- SOS 전용 탐사지 맵과 Radio Interference 전용 탐사지의
  실제 맵/안테나 3개 콘텐츠는 V37.2.1~에서 이어서 구현할 예정.
