AFTERGLOW V37.0 - CCTV STEP 1

이번 단계에서 실제 구현:
- 기존 벙커 내부 CAM1~4 방식 제거
- Security Camera를 '무너진 집 바깥 + 벙커 입구' 감시 화면으로 변경
- Door Defense 서버 상태 추가 (0~100)
- Door Defense가 플레이 중 30초마다 1 감소
- 컴퓨터 CCTV 화면에 Door Defense 게이지 표시
- 전력 0이면 CCTV NO SIGNAL
- 저전력일 때 CCTV 노이즈
- 해킹 상태에서는 CCTV 잠금
- Door Defense 충전 버튼 (현재 단계에서는 즉시 100%)
- 서버/클라이언트 동기화

다음 단계(V37.1 예정):
- 외부 적 스폰
- 집 밖에서 벙커 문까지 접근
- 적이 Door Defense 공격
- Door Defense 0에서 벙커 침입
- 침입한 적을 실제 벙커 몹으로 생성
