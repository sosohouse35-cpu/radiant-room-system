AFTERGLOW V36 - BUNKER SYSTEMS

적용 내용
1. FIREWALL
- 바이러스 1개
- 화면에 탄환 최대 1발
- 탄환 발사 간격/속도 하향
- 실패 시 Firewall 칸 유지
- 시간 경과로만 Firewall 감소
- 성공 시 6칸 완전 복구

2. 발전기
- 3단계 타이밍 게임
- 단계가 올라갈수록 속도 증가 / 성공 구간 감소
- 1~2단계 성공만으로 전력 증가 없음
- 3단계 전부 성공 시 전력 100%
- 실패 시 기존 전력 유지
- 배터리 1개 사용 시 전력 100%

3. CCTV
- 컴퓨터 CCTV 메뉴에서 전체/CAM1~4 선택
- 현재 벙커 화면을 카메라 구역별로 표시
- 저전력 시 노이즈
- 전력 0 시 CCTV 화면 NO POWER

4. 컴퓨터 해킹
- 해킹 상태에서는 CCTV/SECURITY/BOUNTY/SHOP 모두 사용 불가
- 해킹 해제 자원 투입 기능만 사용 가능
- 비용: 물 2 + 통조림 2 + 배터리 1
- 서버 상점 구매도 해킹 상태에서 차단

5. 침대
- 기존 수면/암전/양 3회 애니메이션 유지

6. 메디킷
- 환풍구를 가리지 않는 오른쪽 벽 쪽 위치 유지
