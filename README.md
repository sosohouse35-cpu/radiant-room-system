# Afterglow Shelter 방 만들기 시스템

Radiant Residents처럼 여러 사람이 방을 만들고 참가하는 흐름을 연습하기 위한 독립적인 프로토타입입니다.

## 포함 기능

- 공개방 생성 및 목록 표시
- 비공개방 생성
- 6자리 방 코드 참가
- 빠른 참가
- 최대 2~8명 설정
- 준비/준비 취소
- 방장만 게임 시작
- 방장 퇴장 시 자동 위임
- 게임 시작 후 추가 입장 차단
- 모바일 화면 대응

## 실행

Node.js가 설치된 폴더에서:

```bash
npm install
npm start
```

브라우저:

```text
http://localhost:3000
```

같은 와이파이의 다른 기기에서는 서버 컴퓨터의 IPv4 주소를 사용합니다.

```text
http://192.168.x.x:3000
```

Windows 방화벽에서 Node.js 네트워크 접근을 허용해야 할 수 있습니다.

## 다음 연결 지점

`public/app.js`의 `game-started` 이벤트에서 현재 임시 카운트다운 화면 대신 실제 게임 장면을 열면 됩니다. 게임 중 플레이어 위치, 아이템, 제한 시간, 승패 판정은 서버에서 관리하는 것이 안전합니다.

## 주의

현재 방 정보는 서버 메모리에만 저장됩니다. 서버를 재시작하면 모든 방이 사라집니다. 여러 서버 인스턴스로 확장하려면 Redis 기반 Socket.IO 어댑터와 영속 데이터베이스가 필요합니다.
